Rosters grow like crowds at a pay-per-view. The Librarian keeps them sorted by brand, alignment, and specialty, letting you find any superstar in a heartbeat.

Experimentation is healthy, but losing a beloved configuration is not. Snapshots capture your entire setup and restore it on demand.

### Session Notes
Wrestling is improv. Notes capture those flashes of brilliance so you can circle back to them tomorrow.

## 🎨 Design Philosophy

- **Calm over chaos** — The interface breathes. Whitespace is a feature, not a bug.
- **Clarity over cleverness** — Every label says what it does.
- **Reversibility over regret** — Destructive actions require confirmation and offer undo.
- **Accessibility as standard** — High-contrast modes, keyboard navigation, and scalable typography.
- **Local-first** — Your data stays where you left it.

## 🛎️ 24/7 Customer Support

Round-the-clock assistance is part of the promise. Support channels are documented in the repository wiki, with guided triage steps for common situations:

- Launcher refuses to start → verify runtime presence and log location.
- Panels appear empty → confirm the workspace folder was not relocated.

**Is this the same as other trainers?**
No. Ringmaster Companion prioritizes structure, safety, and usability over raw feature count.

It works within documented workspace folders and always offers rollback snapshots.

**Does it need internet access?**
No. It runs entirely offline unless you opt into update checks.

**Can I use it on Windows 10 and 11?**
Yes — both are fully supported in 2026.
